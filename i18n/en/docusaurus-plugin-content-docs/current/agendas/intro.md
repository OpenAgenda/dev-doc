# Agendas

```http
[GET/POST/DELETE] /v2/agendas
```

The routes documented in the Agendas section allow you to view various parameters and data specific to an agenda, excluding events which are documented in a dedicated section.

* [Agenda Search](/agendas/recherche): list agendas published on the platform.
* [Configuration](/agendas/lecture): retrieve and read the details of an agenda's configuration.
* [Schemas and Additional Fields](/agendas/schemas): how to extend the event form
* [Source Agendas](/agendas/sources): list an agenda's sources
* [My Agendas](/agendas/mes-agendas): list agendas where the authenticated user is a member
