# Node.js Portal

A node.js library that allows you to deploy a white-label event portal. It is available on [npm](https://www.npmjs.com/package/@openagenda/agenda-portal) and on [github](https://github.com/OpenAgenda/oa-public/tree/main/agenda-portal).

Some implementations:

* [Loiret Agenda](https://sortir.loiret.fr)
* [Senlis Agenda](https://agenda.ville-senlis.fr)
* [Cap Métiers](https://agenda.cap-metiers.pro)
