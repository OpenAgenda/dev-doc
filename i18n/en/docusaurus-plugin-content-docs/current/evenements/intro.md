# Events of an agenda

```bash
[GET/POST/PUT/DELETE] /v2/agendas/{agendaUID}/events
```

This route allows you to manage events referenced on an agenda: create events, update them, remove them... The operations are detailed in the following pages:

* [Structure](/evenements/structure): how an event is composed
* [Reading](/evenements/lecture): view one or more events, filter and search
* [Creation](/evenements/creation): create a new event
* [Editing](/evenements/edition): make changes to an event
* [Deletion](/evenements/suppression): remove or delete an event from an agenda
