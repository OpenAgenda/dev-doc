# Drupal Extension

The Drupal module allows you to integrate your agendas hosted on <https://openagenda.com> directly on your Drupal 8, 9, or 10 site.

The module code is available on [drupal.org](https://www.drupal.org/project/openagenda).

Once installed, the integrator can choose which filters to add, customize templates and styles.

Filters can be added via blocks presented in the Drupal site administration. It is also possible to integrate them directly via HTML codes in the page. To learn more, click here: <https://www.npmjs.com/package/@openagenda/react-filters>

Some implementation examples:

* [Bordeaux Metropolitan Area](https://www.bordeaux-metropole.fr/agenda)
* [Nantes Metropolitan Area](https://metropole.nantes.fr/que-faire-nantes/agenda)
* [Industry Week](https://www.entreprises.gouv.fr/semaine-de-lindustrie)
