# Plugins & integrations

Several libraries and tools allow you to integrate agendas on websites:

* The [Embed code](https://developers.openagenda.com/en/en/plugins/embeds.md) is the fastest way to add a fully functional agenda with filters, list view and detail view to your site. A code snippet is placed on the page where the agenda should appear and you're all set.
* Plugins are available for [Wordpress](https://developers.openagenda.com/en/en/plugins/wordpress.md), [Drupal](https://developers.openagenda.com/en/en/plugins/drupal.md) and [Typo3](https://developers.openagenda.com/en/en/plugins/typo3.md). They allow full customization of the rendering of integrated agendas.
* Alternatively, a [dedicated event portal](https://developers.openagenda.com/en/en/plugins/agenda-portal.md) can be customized and deployed in its own environment.
