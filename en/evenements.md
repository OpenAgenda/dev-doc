# Events of an agenda

```
[GET/POST/PUT/DELETE] /v2/agendas/{agendaUID}/events
```

This route allows you to manage events referenced on an agenda: create events, update them, remove them... The operations are detailed in the following pages:

* [Structure](https://developers.openagenda.com/en/en/evenements/structure.md): how an event is composed
* [Reading](https://developers.openagenda.com/en/en/evenements/lecture.md): view one or more events, filter and search
* [Creation](https://developers.openagenda.com/en/en/evenements/creation.md): create a new event
* [Editing](https://developers.openagenda.com/en/en/evenements/edition.md): make changes to an event
* [Deletion](https://developers.openagenda.com/en/en/evenements/suppression.md): remove or delete an event from an agenda
