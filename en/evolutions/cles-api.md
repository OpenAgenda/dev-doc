# API key permissions

**Period: September 2026**

Finer-grained permissions for API keys will be rolled out during September 2026. They will make it possible to:

1. set an expiry date for a given key;
2. define the allowed operations as well as the agendas they apply to.

These changes concern keys associated with user accounts. Keys already in use will not be affected.

See [Authentication](https://developers.openagenda.com/en/en/authentification.md) for the current usage of keys.
