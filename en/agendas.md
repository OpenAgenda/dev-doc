# Agendas

```
[GET/POST/DELETE] /v2/agendas
```

The routes documented in the Agendas section allow you to view various parameters and data specific to an agenda, excluding events which are documented in a dedicated section.

* [Agenda Search](https://developers.openagenda.com/en/en/agendas/recherche.md): list agendas published on the platform.
* [Configuration](https://developers.openagenda.com/en/en/agendas/lecture.md): retrieve and read the details of an agenda's configuration.
* [Schemas and Additional Fields](https://developers.openagenda.com/en/en/agendas/schemas.md): how to extend the event form
* [Source Agendas](https://developers.openagenda.com/en/en/agendas/sources.md): list an agenda's sources
* [My Agendas](https://developers.openagenda.com/en/en/agendas/mes-agendas.md): list agendas where the authenticated user is a member
